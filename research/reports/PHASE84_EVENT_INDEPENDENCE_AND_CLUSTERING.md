# Phase 84 — Event Independence and Clustering Robustness
Date: 2026-10-03

## Purpose

Test whether the frozen H-M6 delayed-movement result is materially created by dependent/overlapping event windows or by a small number of unusually dense event days.

This is a robustness audit only. H-M1 and H-M6 definitions are unchanged. No new filter, target, stop, horizon, or entry rule is introduced.

## Data and unit of analysis

- Exact Apr-Sep 2026 NIFTY monthly-futures 5-minute data.
- Official frozen event universe: 513 events; validation split: 255 events.
- Validation comparison: H-M6 versus the same non-H-M1 control used in Phase 82.
- Primary endpoint: same-session 20-bar direction-adjusted return (`ret20atr`) from the next-bar execution reference, already defined in the frozen event table.
- Event spacing is measured in exact futures-bar positions within the same contract and same trading session.
- To avoid artificially linking separate trading sessions, cooldown/de-overlap tests reset at each session boundary.

## 1. Event spacing

| Validation group | n | Median same-day gap | Mean same-day gap | Gap <=5 bars | Gap <=10 bars | Gap <=20 bars |
|---|---:|---:|---:|---:|---:|---:|
| H-M6 | 54 | 13 | 15.53 | 29.8% | 36.2% | 70.2% |
| Control | 189 | 12 | 14.58 | 19.9% | 37.6% | 78.0% |

H-M6 events are therefore clustered, but the control is similarly clustered. There is no evidence that H-M6 alone is uniquely generated by denser event timing.

## 2. Same-session cooldown / non-overlap test

A deterministic chronology-preserving thinning rule was applied within each contract-session: retain the first official event, then retain a later event only when it is at least N completed bars after the previously retained event. N was evaluated at 5, 10, 20 and 30 bars.

The 20-bar threshold is the key independence stress test because Phase 82's primary delayed endpoint is a 20-bar horizon. It prevents two retained events from sharing that 20-bar outcome window within a session.

| Cooldown | H-M6 n | Control n | H-M6 ret20 | Control ret20 | Delta |
|---:|---:|---:|---:|---:|---:|
| 0 | 54 | 189 | +1.454 | +0.010 | +1.443 ATR |
| 5 | 41 | 165 | +1.410 | +0.003 | +1.407 ATR |
| 10 | 38 | 149 | +1.427 | -0.018 | +1.445 ATR |
| 20 | 31 | 107 | +1.479 | +0.129 | +1.350 ATR |
| 30 | 24 | 90 | +1.479 | +0.463 | +1.016 ATR |

The point estimate remains positive after enforcing the 20-bar non-overlap condition. At 30 bars the effect weakens, indicating that the result is not immune to how aggressively the event sequence is collapsed.

## 3. Day-block uncertainty after de-overlap

Day-block bootstrap probabilities were recomputed on each thinned sample. For the primary 20-bar cooldown, the H-M6-minus-control point estimate was +1.350 ATR with a 95% day-block interval of approximately [-0.154, +3.125] and bootstrap P(delta <= 0) approximately 0.043.

At 30 bars, the point estimate was +1.016 ATR with a 95% interval of approximately [-0.635, +3.102] and P(delta <= 0) approximately 0.141.

Thus the delayed-movement effect survives an independence stress test in point-estimate terms, but its uncertainty grows as the event sample is made more independent.

## 4. Equal-day weighting without event thinning

To test whether event frequency inside a day is dominating the original point estimate, each validation day was given equal weight after first averaging its H-M6 and control event returns. On the 33 days containing both groups:

- mean daily H-M6-minus-control difference: +1.463 ATR;
- median daily difference: +0.805 ATR;
- positive-day share: 66.7%;
- 10%-trimmed daily difference: +0.849 ATR;
- day-resampled 95% interval: approximately [+0.245, +2.849] ATR.

This is supportive evidence that the original result is not simply a consequence of days containing more H-M6 events.

## 5. Important limitation exposed by the audit

The strictest construction — same-session 20-bar de-overlap followed by comparison only on days that still contain both groups — leaves only 24 common days and produces a much weaker equal-day difference. The event-weighted 20-bar-de-overlapped delta remains +1.350 ATR, but the paired common-day estimate is not stable enough to treat as independent confirmation.

This distinction matters:

- the H-M6 movement point estimate is robust to ordinary event-overlap removal;
- the stronger claim that the effect is independently present on matched days after aggressive episode collapse is not established.

## Scientific conclusion

Phase 84 does **not** invalidate H-M6, but it reduces the confidence that can be assigned to the 2026 in-sample movement result.

The evidence now supports the narrower statement:

**H-M6 is associated with delayed directional path persistence in this 2026 futures sample, and that association survives moderate event de-overlapping; however, strict episode-level independence leaves materially wider uncertainty.**

This remains a research finding, not a validated trading rule.
