# Research Git Autosave Policy

For every autonomous research phase:
1. Commit the main report.
2. Commit every derived CSV, table, dataset extract, audit artifact, and supporting file generated during the phase.
3. Verify committed files on GitHub before reporting completion.
4. Do not knowingly leave a generated artifact only in the local workspace.
5. For unusually large artifacts, use a lossless transfer/assembly method and verify integrity with SHA-256 before considering the save complete.
