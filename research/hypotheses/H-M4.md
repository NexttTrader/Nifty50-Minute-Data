# H-M4 — Higher-Timeframe Alignment

## Statement
H-M1 events may become more informative when the completed 15-minute directional state agrees with the 5-minute breakout direction.

## Current evidence
Validation:
- H-M1 + 15m SALMA agreement: mean R3 about +0.298R, mean 20-bar signed return +1.433 ATR, MFE 3.513 ATR, MAE 1.551 ATR.
- H-M1 + 15m SALMA disagreement: mean R3 about +0.040R, signed return +0.621 ATR, MFE 2.243 ATR, MAE 1.888 ATR.

Generic 15-minute moving-average alignment also conditioned candidate outcomes positively, so the current evidence favors a generic higher-timeframe state interpretation rather than a uniquely SALMA-specific mechanism.

## Status
UNVALIDATED.
